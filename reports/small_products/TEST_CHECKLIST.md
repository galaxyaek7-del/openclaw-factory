# Prompt pack testing checklist

Founder tests each prompt on ChatGPT (or another assistant). The factory cannot run these tests: it has no ChatGPT access, and a rating must come from a real response.
Source of the prompts: `data/prompt_packs.json` (also in each pack's `README.md`).

## How to test each prompt
1. Fill the [ ] placeholders with a realistic example (e.g. Grade 5, science, fractions).
2. Paste the prompt into ChatGPT-4 and read the response.
3. Rate it: **EXCELLENT** (usable as-is), **GOOD** (usable with light edits), **WEAK** (needs rewriting), **REMOVE** (fails or is unsafe).
4. Note anything wrong: wrong Arabic, invented facts, ignored placeholders.

## After testing
Send the filled tables back. The factory then records the results, removes or rewrites what was rated WEAK/REMOVE, and runs the pack through the quality gate.
Until then, neither pack is tested. Neither is listed on Gumroad.
