# Python dependencies for OpenClaw Factory (Phase 10C — CI reproducibility).
#
# Pinned, not floating, so a clean `pip install -r requirements.txt` reproduces
# a known-good environment on CI. Corrected 2026-10-04: this header used to
# claim every pin was taken from "what this session's real environment has
# installed and verified working". That had drifted -- the developer machine has
# reportlab 5.0.1 and pypdf 6.19.0 while CI installs 5.0.0 and 6.14.2. Both
# sets are known-good, so the pins were left alone and the claim corrected
# rather than the reverse.
#
# Every entry below was added because tracked code genuinely imports it and a
# clean CI environment genuinely lacked it. Locally invisible each time, because
# this machine happens to have the package installed. Keep that in mind before
# adding anything here: `pip install` something locally and CI will not have it.
reportlab==5.0.0
# Bumped from 12.2.0 (Enterprise Security & Cyber Defense Mission, Phase 1
# Security Audit, 2026-07-23, finding 2.6): pip-audit found 10 real,
# published CVEs against 12.2.0 (PYSEC-2026-2253/2254/2255/2256/2257,
# PYSEC-2026-3451/3452/3453/3454, CVE-2026-54058/59198/59200/59204).
# Pillow is load-bearing for real cover-image generation -- every product
# this factory ships touches it.
Pillow==12.3.0
pypdf==6.14.2
# Real, unguarded top-level dependency of channels/gumroad_publisher.py and
# channels/paddle_publisher.py (both `import requests` with no try/except) —
# found missing from this file during the 2026-07-18 architecture review;
# never caught locally because CI has never actually run on GitHub's own
# infrastructure yet (a separate, already-known gap), so a clean `pip
# install -r requirements.txt` environment was never actually exercised.
requests==2.34.2

# Real dependency of niche_validator_v2.py (`from bs4 import BeautifulSoup`),
# which book_generator.py imports for its Quality Gate. Found 2026-10-04: seven
# book_generator CLI tests failed on CI with "Expecting value: line 1 column 1"
# because bs4 was absent there, so the module's import-time error message landed
# on stdout ahead of the CLI's JSON. Locally invisible -- bs4 is installed here.
# Same class as the `requests` entry above: a dependency of shipped code that
# this file never declared.
beautifulsoup4==4.15.0

# Optional, but genuinely load-bearing for output QUALITY, so they are declared
# rather than left to chance. cover_designer_v2.py and inspectors.py reshape and
# bidi-reorder Arabic before drawing it, because Pillow draws raw codepoints and
# unshaped Arabic renders garbled or as missing-glyph boxes. Arabic is this
# factory's dominant script (see CLAUDE.md). Both imports are guarded, so
# nothing breaks without them -- every cover just quietly renders worse.
arabic-reshaper==3.0.1
python-bidi==0.6.11

# Real dependency of channels/x_arm.py's OAuth1 request signing
# (`import oauthlib.oauth1`), and patched directly by tests/test_x_arm.py.
# Its absence in CI surfaced as
# "ModuleNotFoundError: No module named 'oauthlib'" -- the arm itself degrades
# honestly when it is missing, but the test could not even patch the target.
# Third undeclared dependency of shipped code, same class as requests and
# beautifulsoup4 above.
oauthlib==4.0.0

# Found by scripts/audit_requirements.py, which walks every third-party import
# in tracked code against this file. Both are installed and used in shipped
# paths; neither was declared, and both are invisible locally for the same
# reason requests/bs4/oauthlib were.
#   python-dateutil -> portfolio_routing.py
#   tenacity        -> lib/http.py (bounded retries on the shared JSON client)
python-dateutil==2.9.0.post0
tenacity==9.1.4
