# إعداد تنبيهات Telegram (F5): خطوة بخطوة

الحالة الملاحَظة في 2026-11-05: البوت `OpenClaw_Abdelkader_bot` موجود ورمزه (`TELEGRAM_BOT_TOKEN`) مضبوط في `.env`، لكن **لا توجد محادثة** له معك، و`OPENCLAW_TELEGRAM_CHAT_ID` غير مضبوط. لذلك لا يصلك أي تنبيه حتى لو سقطت الحلقة. المطلوب منك شيئان فقط: أن تكتب للبوت مرة، وأن تضع رقم محادثتك في `.env`.

لا تحتاج إلى مفتاح جديد ولا إلى دفع. رقم المحادثة ليس سراً، لكن لا ترسل رمز البوت لأحد.

## الخطوات

1. **افتح Telegram على هاتفك** (أو على الحاسوب) واكتب في البحث: `@OpenClaw_Abdelkader_bot`.
2. **افتح البوت واضغط Start** (أو أرسل `/start`). ثم أرسل له كلمة أي كلمة، مثلاً `مرحبا`. هذا ضروري: البوت لا يستطيع مراسلتك قبل أن تكتب له أنت أولاً.
3. **اجلب رقم محادثتك.** في نافذة Claude Code اكتب (مع علامة `!` في البداية):
   ```
   ! python scripts/n8n_notification_selfcheck.py --json
   ```
   ابحث في الناتج عن `discoverable_chat_ids` وخذ الرقم (عدد من 9 إلى 10 خانات تقريباً). إن رأيت `"updates_seen": 0` فمعنى ذلك أن الخطوة 2 لم تصل بعد: أعد كتابة رسالة للبوت وكرر الأمر.
4. **ضع الرقم في `.env`.** افتح الملف `C:\openclaw-dasgboard\.env` بالمفكرة (Notepad) وأضف سطراً جديداً في آخره (بدون مسافات ولا علامات اقتباس):
   ```
   OPENCLAW_TELEGRAM_CHAT_ID=123456789
   ```
   (ضع رقمك بدل المثال) ثم احفظ الملف. الملف غير مرفوع إلى git ولا يُنشر.
5. **أعد تشغيل الخادم والحلقة** كي يقرآ القيمة الجديدة. أسهل طريقة: اكتب لي "أعد التشغيل" وأنا أفعلها بأمان (أوقف العمليتين بمعرّفهما الدقيق، فيعيدهما المراقب `supervisor` تلقائياً، ولا أستعمل `taskkill /IM node.exe` أبداً).
6. **اختبر.** اكتب:
   ```
   ! python -m gf_ops.alerts --subject "اختبار التنبيه" --body "إذا وصلتك هذه الرسالة فالتنبيهات تعمل" --category OPS
   ```
   يجب أن تصلك رسالة على هاتفك خلال ثوانٍ، ويطبع الأمر `"delivered": true`.
7. **تحقق أن الفحص اليومي رضي:**
   ```
   ! python scripts/n8n_notification_selfcheck.py
   ```
   يجب أن يظهر `chat id configured: True`.

## إن لم تصل الرسالة

- تأكد أنك ضغطت Start على البوت **الصحيح** (`OpenClaw_Abdelkader_bot`) وليس بوتاً آخر بنفس الاسم تقريباً.
- تأكد أن السطر في `.env` بصيغة `NAME=value` بلا مسافات وأن الرقم هو رقم **محادثتك أنت** لا رقم البوت.
- ظهور `error` في ناتج الخطوة 6 يخبرنا بالسبب (مثلاً `chat not found` يعني أنك لم تكتب للبوت بعد).
- لا ترسل لي رمز البوت. يكفيني نص الخطأ.

## ملاحظة تقنية

مسارا التنبيه: (أ) مباشر من البايثون عبر `channels/telegram_direct.py` ويحتاج الرمز + رقم المحادثة فقط، و(ب) عبر ويب هوك n8n الذي يفشل حالياً لأن n8n يمنع قراءة `$env` (`N8N_BLOCK_ENV_ACCESS_IN_NODE`). الخطوات أعلاه تُفعّل المسار (أ)، وهو الأبسط والأكثر استقراراً، فلا تحتاج إلى إصلاح n8n من أجل التنبيهات.
