# نشر فيديو systeme.io بيدك (أول إشارة عمولة خارجية)

الحالة المقاسة: كل فحوص الجاهزية المحلية ناجحة (`python -m affiliate.systeme_readiness`)، **لم يُنشر شيء**، ولا نقرة خارجية، ولا عمولة (0). النشر العام وإدخال معرّفك خطوتان لك وحدك، ولا أفعلهما.

**UNKNOWN:** هل اعتمد systeme.io حساب الإحالة؟ تأكد أولاً: ادخل `https://systeme.io/dashboard/affiliate-dashboard` وتحقق أن الحساب فعّال وأن المعرّف الظاهر هناك هو نفسه المضبوط في `.env`.

## الخطوات

1. **اطبع رابطك الحقيقي على شاشتك فقط** (لا تنسخه إلى أي ملف في المستودع):
   ```
   python -c "from systeme_affiliate import get_affiliate_url; print(get_affiliate_url())"
   ```
   إن ظهر خطأ `ConfigError` فالمعرّف غير مضبوط أو غير صالح الصيغة.
2. **افتح قناتك الخاصة** (YouTube مثلاً) وارفع `assets/affiliate/systeme_io/publication_package/final_video.mp4`.
3. **العنوان:** اختر من `title_candidates.md` في المجلد نفسه.
4. **الوصف:** الصق `description_ar.md`، واستبدل `https://systeme.io/?sa=__SA_ID_FROM_ENV__` بالرابط من الخطوة 1. **أبقِ فقرة الإفصاح** (أنها رابط إحالة) كما هي: هي شرط الثقة والقانون.
5. **الصورة المصغّرة:** `thumbnail_final.png`. **الترجمة:** `subs_final.srt`.
6. انشر.
7. **افتح الفيديو من نافذة خاصة** وتأكد أن الرابط في الوصف يفتح systeme.io، وأن العنوان في المتصفح يحمل `?sa=`.
8. أخبرني بالرابط العام للفيديو لأسجّله، فلا أخترع أي رقم مشاهدات.

## بعد النشر

- النقرات الخارجية والمشاهدات: **لا أستطيع قياسها** (لا مستقبل تحليلات بعد). المصدر الوحيد الصادق الآن هو لوحة systeme.io الخاصة بك.
- حين ترى إحالة أو عمولة فيها، سجّلها هكذا (تجربة بلا كتابة بدون `--apply`):
  ```
  python scripts/record_real_commission.py --amount 29.5 --status PENDING --evidence "لوحة systeme.io التاريخ والإحالة" --apply
  ```
  عند الدفع الفعلي: `--status PAID --txid <رقم معاملة systeme.io>`.
- لا تعتبر الفيديو ناجحاً قبل أول عمولة PAID. الصفر هنا هو الحقيقة حتى يثبت غيره.
