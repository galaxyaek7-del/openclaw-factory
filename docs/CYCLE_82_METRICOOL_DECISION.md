# قرار Metricool — البند 4 من الدورة 82

## الخلاصة: **لا تشترك بأي ترقية. اشتراكك الحالي لا يدعم API.**

---

## الدليل (محقق حيًا هذه الدورة وفي الدورات السابقة، ليس افتراضًا)

1. **التوثيق الرسمي الحالي لـ Metricool:** قسم رمز API في إعدادات الحساب "يظهر فقط" لباقتي **Advanced** أو **Custom** (مؤكد عبر مراجع التوثيق الرسمي).
2. **اختباران حيّان مباشران هذه الدورة/السابقة** على بيانات اعتماد حقيقية موجودة في `.env` (`METRICOOL_USER_TOKEN`, `METRICOOL_USER_ID`, `METRICOOL_BLOG_ID` — القيم لم تُطبع أبدًا): كلا طريقتي المصادقة المجرّبتين (`X-Mc-Auth` header والطريقة القديمة `userToken=` كـ query param) أعادتا **401 Unauthorized** على كل نقطة نهاية جُرّبت.
3. **تأكيد مستقل سابق داخل الكود نفسه:** `channels/capability_matrix.py` (ملف غير مُتتبَّع، لكنه موجود على القرص من فرع سابق) يحتوي فعليًا على نفس النتيجة: `channels["metricool"]` بملاحظة `"OPTIONAL DISTRIBUTION PROVIDER. Token returns 401 on all endpoints. Not core infrastructure. Do NOT upgrade."` — نتيجة مطابقة تمامًا لاختبار هذه الدورة المباشر، مسجَّلة قبل هذه الدورة.

## القرار المطبَّق هذه الدورة

**لم يُشترك بأي شيء.** تم بدلاً من ذلك بناء بديل بميزانية 0 دولار: طابور محتوى أسبوعي (`content_queue`) بصيغتي CSV وMarkdown، لتُجدوِله بنفسك يدويًا عبر واجهة المنصات (فيسبوك/إنستغرام/تيك توك) مباشرة. انظر `data/content_queue_cycle82.csv` و`docs/CONTENT_QUEUE_CYCLE82.md`.

## متى يُعاد النظر

فقط إذا رقّيت اشتراك Metricool فعليًا إلى Advanced/Custom بنفسك (قرار حساب/دفع خارج صلاحياتي) — عندها يمكن بناء تكامل جدولة حقيقي عبر API الرسمي بدلاً من الطابور اليدوي.
