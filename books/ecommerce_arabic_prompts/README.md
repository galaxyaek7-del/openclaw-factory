# ٢٥ موجّهاً جاهزاً للتجارة الإلكترونية (بالعربية)

> حزمة أوامر (Prompts) جاهزة لكتابة وصف المنتجات، الإعلانات، رسائل العملاء، وصفحات البيع — بالعربية، مع أي مساعد ذكاء اصطناعي.

---

## كيف تستخدمها؟

1. انسخ الأمر المناسب.
2. استبدل `[ ]` بتفاصيل منتجك.
3. راجع الناتج، عدّل النبرة، وتحقق من كل رقم أو وعد قبل النشر.

> **قاعدة أساسية:** لا تنشر أي وعد لا تستطيع الوفاء به، ولا رقم مبيعات لم يحدث فعلاً. الصدق في التسويق يحمي متجرك.

---

## قائمة الموجّهات (٢٥)

### 1) وصف منتج يحوّل (بصيغة AIDA)
```
اكتب وصفاً لمنتج [اسم المنتج] يستخدم صيغة (انتباه - اهتمام - رغبة - إجراء).
اذكر: الفائدة الرئيسية أولاً، [٣] فوائد فرعية، ولمن هذا المنتج.
الطول: [١٢٠] كلمة. النبرة: واضحة وبسيطة بلا مبالغة.
```

### 2) عنوان منتج محسّن لمحركات البحث
```
اقترح [٥] عناوين لمنتج [اسم المنتج]، كل عنوان أقل من [٧٠] حرفاً،
يحتوي الكلمة المفتاحية [الكلمة] بشكل طبيعي، ويجذب النقر دون تضليل.
```

### 3) كلمات مفتاحية طويلة الذيل
```
اقترح [١٥] كلمة مفتاحية طويلة الذيل لمنتج [المنتج] الذي يستهدف [الجمهور]،
مصنّفة إلى: نيّة شرائية، معلوماتية، ومقارنة. لكل كلمة اذكر سبب اختيارها.
لا تذكر أحجام بحث أو أرقاماً لا تملك مصدراً لها.
```

### 4) نص إعلان فيسبوك
```
اكتب نص إعلان فيسبوك لمنتج [المنتج] موجّه لـ[الجمهور].
النص: [٨٠] كلمة، يبدأ بمشكلة العميل، ثم الحل، ثم دعوة واضحة للإجراء.
اقترح كذلك نصاً قصيراً للزر. لا تستخدم ادعاءات غير مثبتة.
```

### 5) نص إعلان إنستغرام
```
اكتب [٣] نسخ نصية قصيرة لإعلان إنستغرام عن [المنتج]،
كل نسخة أقل من [٤٠] كلمة، مع [٥] وسوم مناسبة وصيغة سؤال تبدأ التفاعل.
لا تخترع أرقاماً أو ادعاءات غير مثبتة.
```

### 6) سلسلة تغريدات لإطلاق منتج
```
اكتب سلسلة من [٦] تغريدات لإطلاق [المنتج]:
الأولى تطرح المشكلة، الوسطى تعرض الحل والفوائد، الأخيرة دعوة ومحتوى مجاني.
كل تغريدة أقل من [٢٨٠] حرفاً. لا تخترع أرقاماً أو ادعاءات غير مثبتة.
```

### 7) بريد ترحيبي للمشتركين الجدد
```
اكتب بريداً ترحيبياً لمن اشترك حديثاً في قائمة [المتجر / النشرة]:
شكر قصير، ما سيحصل عليه، هدية أو نصيحة فورية، وتوقع لما سيصله لاحقاً.
الطول: [١٥٠] كلمة، النبرة: ودّية ومهنية.
```

### 8) سلسلة بريدية للبيع (٣ رسائل)
```
اكتب [٣] رسائل بريد إلكتروني لبيع [المنتج]:
(١) الحكاية والمشكلة، (٢) الفوائد ومعالجة اعتراض، (٣) عرض واضح بمهلة صادقة
(لا تستخدم مهلة وهمية). كل رسالة [٢٠٠] كلمة كحد أقصى.
```

### 9) رد على استفسار عن السعر
```
اكتب رداً مهذّباً على عميل يسأل عن [المنتج]: «لماذا السعر [السعر] مرتفع؟»
أكّد القيمة، اربطها بنتيجة محددة، واقترح البديل الأرخص [البديل الأرخص، إن وُجد]،
واذكر ضمان الاسترجاع إن كان موجوداً فعلاً. لا تخترع بديلاً أو ضماناً غير موجود. الطول: [٨٠] كلمة.
```

### 10) رد على شكوى عميل
```
اكتب رداً على شكوى عميل بشأن [المشكلة] في [المنتج] (لا يزيد على [١٠٠] كلمة):
اعتذار صادق دون تبرير، خطوة حل فورية، وخطوة لتفادي التكرار.
لا تُقرّ بمسؤولية قانونية ولا تَعِد بما لا تستطيع تنفيذه.
```

### 11) طلب تقييم بعد الشراء
```
اكتب رسالة قصيرة لطلب تقييم بعد شراء [المنتج]، تشكر العميل، تطلب تقييماً صادقاً
(وليس تقييماً إيجابياً فقط)، وتبيّن أن رأيه يساعد آخرين. الطول: [٦٠] كلمة.
```

### 12) نص صفحة هبوط
```
اكتب عناوين ونصوصاً لصفحة هبوط لمنتج [المنتج]:
عنوان رئيسي، عنوان فرعي، [٣] فوائد، قسم أسئلة شائعة ([٤] أسئلة)، ودعوة للإجراء.
اجعل كل قسم مختصراً، واستخدم فقط المعلومات التالية للتسليم والاسترجاع والدعم:
[معلومات المتجر: مدة التسليم، سياسة الاسترجاع، طريقة الدعم]. لا تخترع ادعاءات أو أرقاماً.
```

### 13) أسئلة شائعة للمنتج
```
اكتب [٦] أسئلة شائعة وأجوبتها لمنتج [المنتج]، تغطي: الاستخدام، التسليم،
الاسترجاع، الدعم، الوقت المتوقع، والفرق عن البدائل. كل جواب في [٣] جمل.
استخدم فقط المعلومات التالية، ولا تخترع سياسات: [معلومات المتجر: مدة التسليم، سياسة الاسترجاع، طريقة الدعم].
```

### 14) مقارنة بين منتجين
```
اكتب مقارنة موضوعية بين [المنتج أ] و[المنتج ب] في جدول:
المعايير، نقاط القوة والضعف لكل واحد، ولمن يصلح كل خيار.
لا تبالغ في مدح منتجك على حساب الآخر.
```

### 15) نص إعلان تخفيض موسمي
```
اكتب نصّاً إعلانياً لتخفيض موسمي ([العيد / الجمعة البيضاء]) على [المنتج] (لا يزيد على [٦٠] كلمة):
اذكر نسبة الخصم الحقيقية [نسبة الخصم]، ومدة العرض الفعلية [مدة العرض]، ودعوة للإجراء.
لا تستخدم عدّاداً وهمياً ولا مبالغة في الندرة.
```

### 16) عنوان بريد إلكتروني يجذب الفتح
```
اقترح [١٠] عناوين لبريد إلكتروني حول [الموضوع]، كل عنوان أقل من [٥٠] حرفاً،
يخلق فضولاً صادقاً دون تضليل. حدد أفضلها ولماذا.
```

### 17) سكريبت فيديو قصير للمنتج
```
اكتب سكريبت فيديو قصير ([٣٠] ثانية) لمنتج [المنتج]:
٥ ثوانٍ خطف، ١٥ ثانية عرض الفائدة الرئيسية، ١٠ ثوانٍ دعوة للإجراء.
اذكر اللقطات المقترحة لكل جزء، ولا تُظهر فيها نتائج أو شهادات غير حقيقية.
```

### 18) سياسة الاسترجاع
```
اكتب مسودة سياسة استرجاع واضحة لمتجر [النوع]:
المدة، الحالات المشمولة والمستثناة، خطوات الطلب، ومن يصدر قرار الاسترجاع.
بصيغة سهلة القراءة. (راجع المدة والحالات مع مختص وفق قوانين بلدك.)
```

### 19) رسالة السلة المتروكة
```
اكتب [٢] رسائل قصيرة لمن ترك سلته في [المتجر] دون إتمام شراء [المنتج]:
الأولى تذكير لطيف بعد [ساعة]، الثانية بعد [يوم] مع طمأنة حول الدفع/التسليم.
لا تستخدم إحراجاً ولا ندماً مصطنعاً.
```

### 20) نص إعلان Google
```
اكتب [٣] إعلانات نصية لمنتج [المنتج]:
كل إعلان: عنوانان (٣٠ حرفاً لكل عنوان)، ووصف (٩٠ حرفاً)،
موجّه لنية البحث [الكلمة المفتاحية]. لا تخترع أرقاماً أو ادعاءات غير مثبتة.
```

### 21) تحسين وصف موجود لزيادة التحويل
```
حسّن وصف المنتج التالي ليزيد التحويل: اجعل الفائدة أولاً، اختر جملاً أقصر،
أضف دعوة للإجراء، واحذف أي مبالغة. أبقِ الطول قريباً من [١٢٠] كلمة،
ولا تُضف أي ادعاء أو رقم غير موجود في الوصف الأصلي: [الصق الوصف هنا]
```

### 22) اقتراح باقات (Bundles)
```
اقترح [٣] باقات لمنتجات [القائمة]، لكل باقة: الاسم، المنتجات المشمولة،
سعر مقترح منطقي، والجمهور الذي تصلح له، مع جملة تسويقية واحدة. لا تخترع أرقاماً أو ادعاءات غير مثبتة.
```

### 23) عرض ترويجي محدود
```
صِغ في [٣] جمل عرضاً محدوداً حقيقياً على [المنتج]، يذكر المكافأة [هدية أو خصم]،
وتاريخ انتهائه الفعلي [التاريخ]، وسببه الصادق [السبب]. لا تصطنع ندرة غير حقيقية.
```

### 24) نقاط بيع مختصرة (Bullet points) للمنصات
```
اكتب [٥] نقاط بيع مختصرة لمنتج [المنتج] لمنصة [أمازون / إتسي]:
كل نقطة تبدأ بالفائدة الرئيسية في كلمتين أو ثلاث، أقل من [٢٠٠] حرف،
وبلا كلمات تمنعها المنصة. لا تخترع أرقاماً أو ادعاءات غير مثبتة.
```

### 25) استبيان ما بعد الشراء
```
صمّم استبياناً قصيراً ([٥] أسئلة) يُرسل بعد شراء [المنتج] لقياس الرضا،
يشمل: سهولة الشراء، جودة المنتج، الدعم، وهل يوصي به — مع سؤال مفتوح واحد.
```

---

## ملاحظات مهمة

- **لا تنشر ادعاءات غير مثبتة:** لا أرقام مبيعات وهمية، ولا تقييمات مختلقة، ولا «الأفضل في السوق» بلا دليل.
- **تحقق من كل رقم** (خصم، مهلة، إحصائية) قبل النشر.
- **راجع السياسات القانونية** (الاسترجاع، الضرائب) مع مختص بحسب بلدك.

---

## الدعم

كل أمر مستقل بذاته. إن أردت ناتجاً أطول أو أقصر، أضف: «اجعل الطول [العدد] كلمة» أو «اختصر إلى [عدد] أسطر».
