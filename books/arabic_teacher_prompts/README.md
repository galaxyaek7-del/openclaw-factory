# ٢٠ موجّهاً جاهزاً للمعلّم العربي

> حزمة أوامر (Prompts) جاهزة للاستخدام مع أي مساعد ذكاء اصطناعي (ChatGPT، Claude، Gemini…). انسخ الأمر، غيّر ما بين الأقواس، واحصل على نتيجة قابلة للاستخدام في الصف مباشرة.

---

## كيف تستخدمها؟

1. اختر الأمر المناسب.
2. انسخه كما هو.
3. استبدل الأقواس `[ ]` بمعلوماتك (الصف، المادة، عدد الطلاب…).
4. راجع الناتج دائماً قبل استخدامه — أنت المعلّم، والأداة مساعدة فقط.

---

## قائمة الموجّهات (٢٠)

### 1) خطة درس متمايزة
```
صمّم خطة درس في [المادة] لصف [الصف] حول موضوع [الموضوع]، مدتها [٤٥] دقيقة.
قسّم الخطة إلى ثلاثة مستويات (مبتدئ / متوسط / متقدّم)، ولكل مستوى هدف واحد
ونشاط واحد وتقييم سريع. اكتب الخطة في جدول.
```

### 2) بنك أسئلة متعدد المستويات (حسب تصنيف بلوم)
```
أنشئ [١٢] سؤالاً حول [الموضوع] لصف [الصف]، موزّعة على مستويات بلوم:
تذكّر، فهم، تطبيق، تحليل. ضع لكل سؤال مستوى الصعوبة ومفتاح الإجابة.
```

### 3) مقياس تقييم (روبرك) لمهمة كتابية
```
أنشئ روبرك لتقييم [مقال / تقرير / قصة] لصف [الصف] بمعايير:
الأفكار، التنظيم، اللغة، الإملاء، والإبداع. استخدم [٤] مستويات (ممتاز/جيد/مقبول/يحتاج تحسيناً)
مع وصف واضح لكل مستوى، والدرجة لكل معيار من [٥].
```

### 4) شرح مفهوم صعب بثلاث طرق
```
اشرح مفهوم [الكسر / الطاقة / الخلية] لطلاب صف [الصف] بثلاث طرق مختلفة:
(١) تشبيه من الحياة اليومية، (٢) مثال بصري يمكن رسمه على السبورة،
(٣) نشاط عملي بمواد بسيطة. اجعل الشرح بلغة سهلة.
```

### 5) نشاط تهيئة في خمس دقائق
```
اقترح [٣] أنشطة تهيئة سريعة (٥ دقائق لكل واحد) لبداية درس [الموضوع] لصف [الصف]،
تُنشّط تفكير الطلاب وتشدّ انتباههم دون تحضير مسبق. اذكر التعليمات بجملتين.
```

### 6) واجب منزلي متدرّج
```
ضع واجباً منزلياً حول [الموضوع] لصف [الصف]، من [٣] أجزاء:
جزء سهل يراجعه الجميع، جزء متوسط يتطلب تفكيراً، وجزء تحدٍّ اختياري للمتقدّمين.
```

### 7) رسالة لأولياء الأمور عن تقدّم الطالب
```
اكتب رسالة قصيرة ومحترمة (لا تزيد على [٦] أسطر) لولي أمر [اسم مستعار للطالب، مثل: الطالب أ]
حول تقدّمه في [المادة]. النبرة: إيجابية وواضحة. اذكر نقطة قوة واحدة، ونقطة تحتاج دعماً،
واقترح خطوة عملية واحدة يفعلها الأهل في المنزل.
```

### 8) خطة علاجية لطالب متأخّر
```
ضع خطة علاجية من [٤] أسابيع لطالب في صف [الصف] متأخّر في [المهارة/الموضوع]،
تشمل: الهدف، مهارات أساسية مفقودة، أنشطة أسبوعية قصيرة، وطريقة قياس التقدّم.
```

### 9) أسئلة مراجعة سريعة (تذكرة خروج)
```
اكتب [٥] أسئلة قصيرة حول درس اليوم ([الموضوع]) لصف [الصف] تُوزّع في آخر [٥] دقائق
كـ«تذكرة خروج»، مع مفتاح إجابة يمكن للمعلّم تصحيحه في دقيقة.
```

### 10) مشروع جماعي بمعايير تقييم
```
صمّم مشروعاً جماعياً حول [الموضوع] لصف [الصف]: الهدف، عدد أفراد المجموعة،
المهام الموزّعة، الجدول الزمني (أسبوعان)، ومعايير التقييم (فردي + جماعي).
```

### 11) تبسيط نص علمي لمستوى الصف
```
أعد كتابة النص التالي بلغة تناسب طلاب صف [الصف]، بجمل لا تتجاوز [١٥] كلمة،
مع الحفاظ على الدقة العلمية وتبسيط المصطلحات. لا تُضف أي معلومة غير موجودة في النص الأصلي،
وإن اضطررت لحذف تفصيل فاذكره في سطر في النهاية: [الصق النص هنا]
```

### 12) سيناريو لعب أدوار لدرس اجتماعي
```
اكتب سيناريو لعب أدوار حول [الموضوع / الموقف] لصف [الصف] بـ[٤] أدوار:
التعليمات لكل دور، [٣] أسئلة يديرها المعلّم بعد التمثيل، والدرس المستفاد.
```

### 13) اختبار قصير مع مفتاح إجابة
```
أنشئ اختباراً قصيراً ([١٠] أسئلة) حول [الموضوع] لصف [الصف]:
[٦] اختيار من متعدد، [٢] صح/خطأ، [٢] سؤال مقالي قصير — مع مفتاح الإجابة والدرجات.
```

### 14) خطة إدارة صف لسلوك متكرّر
```
اقترح خطة للتعامل مع سلوك [المقاطعة المتكررة / عدم إحضار الأدوات] لدى طلاب صف [الصف]:
الخطوات الوقائية، الاستجابة الفورية الهادئة، والخطوات التصاعدية،
مع صيغة تواصل مع الطالب والوالد دون تصعيد.
```

### 15) تحويل درس إلى قصة
```
حوّل درس [الموضوع] إلى قصة قصيرة لصف [الصف] (لا تزيد على [٢٠٠] كلمة)،
بشخصيات واضحة ومغزى واحد يخدم هدف الدرس، ثم ضع [٣] أسئلة فهم بعد القصة.
```

### 16) أسئلة سقراطية لدرس قراءة
```
اقترح [٦] أسئلة سقراطية متدرّجة لطلاب صف [الصف] تقودهم إلى استنتاج [الفكرة الرئيسية / الرسالة]
من النص [العنوان]، بدءاً من أسئلة مباشرة وانتهاءً بأسئلة تحليلية.
```

### 17) خريطة مفاهيمية لوحدة
```
صمّم خريطة مفاهيمية لوحدة [اسم الوحدة] في [المادة] لصف [الصف]، تشمل [٨] مفاهيم رئيسية
ومفاهيمها الفرعية والعلاقات بينها، بصيغة نصية قابلة للرسم على السبورة، مع نقاط التقاء دروس الوحدة.
```

### 18) تقييم تشخيصي في بداية العام
```
أنشئ تقييماً تشخيصياً من [٢٠] سؤالاً في [المادة] لصف [الصف] في بداية العام،
يقيس المهارات الأساسية من العام السابق، مع تصنيف الأسئلة حسب المهارة
ومفتاح تصحيح يوضّح المعالجة المقترحة لكل نتيجة.
```

### 19) بطاقات مهام لمركز تعلّم
```
صمّم [٦] بطاقات مهام (task cards) لمركز تعلّم حول [المهارة] لصف [الصف]،
كل بطاقة تحمل مهمة واحدة واضحة، مواد مطلوبة، وتحدّياً إضافياً سريعاً.
```

### 20) تقرير تقدّم فردي مختصر
```
اكتب تقريراً مختصراً (نصف صفحة) عن تقدّم [اسم مستعار للطالب، مثل: الطالب أ] خلال [الفترة]،
يشمل: مستوى الإنجاز، نقطتَي قوة، نقطة تحسين، ودعماً مقترحاً —
بلغة موضوعية محترمة.
```

---

## ملاحظات مهمة

- **راجع دائماً** أي ناتج قبل عرضه على الطلاب، خصوصاً المحتوى العلمي والديني والتاريخي.
- **خصوصية الطلاب:** لا تُدخل أسماء طلاب حقيقية أو بيانات شخصية في أدوات الذكاء الاصطناعي العامة. استخدم أسماء وهمية مثل «الطالب أ».
- هذه الحزمة **أداة تنظيم وتحضير**، ولا تُغني عن خبرتك التربوية.

---

## الدعم

راجع هذا الملف أولاً؛ كل أمر مصمّم ليقف وحده. إن لم يعطك الناتج ما تريد، أضف للجملة الأولى: «اجعل الرد في جدول»، أو «اجعل اللغة أبسط»، أو «اختصر إلى نصف الصفحة».
