# ADR-048 — Phase 0 Architecture Review: خريطة الطبقات السبع (تحليل فقط)

**التاريخ:** 2026-07-16
**الحالة:** تحليل مكتمل، صفر تغيير كود. بانتظار قرار الرئيس على بندين محدَّدين قبل أي تنفيذ.
**يُنفِّذ:** "Executive Architecture Directive — Phase 0 Foundation."

## القرار

1. **`ARCHITECTURE_REVIEW_2026-07-16.md`** يوثّق جرداً كاملاً للمستودع (منصة أساسية، خدمات مشتركة، وحدات تجارية/ذكاء اصطناعي، بنية تحتية، دَين تقني، تكرار، ترابط محكم، تجريدات مفقودة، مخاطر أمنية، عنق زجاجة) + خريطة كل وحدة موجودة إلى طبقة واحدة من السبع المطلوبة، بلا استثناء.
2. **لا نقل/حذف/دمج ملفات فعلي في هذا الـADR.** الخريطة توثيقية — تُرضي شرط "كل وحدة في طبقة واحدة" بجدول، لا بترحيل فيزيائي (البنية الحالية Core/Engines/Channels من `ADR-034` تبقى كما هي).
3. **اعتراض مُسجَّل مرة (لا يُكرَّر):** بناء "Company Operating System" رسمي كطبقة تنسيق مركزية يقع ضمن تجميد `ADR-034` (لم يتحقق بيع حقيقي/مفتاح API حي/مرشَّح Tier-1 بعد). التقرير يوثّق أن COS لا يوجد فعلياً اليوم (لا `server.js` ولا `factory_loop.js` يلعبان هذا الدور رسمياً)، ويترك قرار البناء الفعلي صراحةً للرئيس.
4. **قراران فعليان معلَّقان** (موثَّقان في §5 من التقرير): (أ) بناء COS حقيقي — يحتاج تجاوزاً صريحاً لتجميد `ADR-034` أو انتظار محفِّز، (ب) توحيد HTTP-fetch المكرَّر بين `market_intelligence_engine.py`/`competitor_discovery.py` + توحيد مسجِّلات النيتش الثلاثة — تحسين هندسي بحت، منخفض الخطر، لا علاقة له بتجميد الطبقة الإدارية، قابل للتنفيذ فوراً بإذن منفصل.

## الأثر

- صفر تغيير على أي كود مصدري.
