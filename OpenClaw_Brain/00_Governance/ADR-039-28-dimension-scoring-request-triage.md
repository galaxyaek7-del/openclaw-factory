# ADR-039 — طلب 28 بُعداً للتسجيل: 2 مُنفَّذان بأدلة حقيقية، 26 مرفوضان صراحةً

**التاريخ:** 2026-07-15
**الحالة:** مُنفَّذ جزئياً + مُختبَر (27 اختباراً في `tests/test_opportunity_score.py`، 6 جديدة).
**يُنفِّذ:** طلب "Market Intelligence V4" — تقييم كل فرصة عبر 28 بُعداً مستقلاً.

---

## القرار

طُلِب 28 مقياساً مستقلاً لكل فرصة. **بعد فحص كل واحد بحثاً عن مصدر بيانات حقيقي — 2 فقط قابلان للتنفيذ بصدق اليوم. البقية الـ26 ترفض عمداً، لا سهواً.**

### الاثنان المُنفَّذان (بيانات حقيقية موجودة فعلاً)

| البُعد | المصدر الحقيقي | لماذا يعمل |
|---|---|---|
| **Risk Score** | `safety_filter.py.evaluate()` (استيراد مباشر، بلا مخاطرة دورة استيراد — `safety_filter.py` لا يستورد `profit_oracle` أبداً) + `REJECTED_NICHES.md` (فحص نصي مباشر) | آليتا أمان حقيقيتان موجودتان فعلاً، لم تُخترَعا اليوم |
| **Confidence Score** | وصفي بحت — هل استُخدِمت إشارة `demand` حقيقية (`ADR-038`)؟ هل يوجد تقرير Amazon محفوظ حقيقي للمنافسة؟ | صدق تعريفي: "كم من هذه النتيجة نعرفه فعلاً، لا نخمّنه" |

**كلاهما إضافي بحت** — حقلان جديدان (`risk`, `confidence`) في مخرجات `score_opportunity()`، **لا يدخلان أبداً في حساب `profit_score`/`verdict`** — صفر أثر على أي قرار قبول/رفض قائم. مُثبَت باختبار: `test_risk_and_confidence_never_change_profit_score_or_verdict`.

### الـ26 المرفوضة صراحةً — لا مصدر بيانات حقيقي اليوم

| البُعد | لماذا لا يوجد اليوم |
|---|---|
| Pricing Power | يحتاج بيانات تجربة تسعير حقيقية — صفر مبيعات فعلية حتى الآن |
| Customer Pain | يحتاج استطلاعات/مراجعات عملاء حقيقية — صفر عملاء |
| Market Growth | يحتاج بيانات تاريخية متعددة النقاط الزمنية — لدينا لقطة واحدة فقط لكل مرشَّح |
| Search Trend | Google Trends غير متصل إطلاقاً — موثَّق كفجوة صريحة منذ البداية |
| Social Trend | صفر وصول لأي API وسائط اجتماعية |
| B2B/B2C/SaaS Potential (كأبعاد منفصلة) | تصنيف نصي من كلمات مفتاحية فقط — نفس مشكلة `ADR-036` بالضبط لو نُفِّذ |
| AI Leverage | مقياس غير مُعرَّف بصيغة قابلة للحساب — لا أحد يعرف ما يعنيه رقمياً |
| Virality | صفر بيانات انتشار حقيقية |
| Evergreen Score | **موجود فعلاً** تحت اسم آخر — `season_score` في `_score_demand()` (موسمي/دائم) — إعادة تسميته "بُعداً جديداً" تضخيم عدد لا قيمة حقيقية |
| Time-to-Market / Technical Complexity / Estimated Development Time | **موجودة فعلاً** تحت اسم `execution_score`/`_score_execution()` — نفس الملاحظة |
| Maintenance Cost | لا بيانات تشغيلية تاريخية كافية بعد (13 يوماً فقط) |
| Revenue Recurrence | جزئياً موجود عبر `PREMIUM_KEYWORDS`/`MID_KEYWORDS` (كلمة "subscription" إلخ) — إعادة تسمية جزء موجود، لا بُعد جديد كامل |
| Customer Lifetime Value / Upsell / Cross-sell Potential | تحتاج بيانات عملاء فعليين — صفر عملاء، لا شيء يُقاس |
| Defensibility / Competitive Moat | يحتاج تحليل منافسين فعلي — لا أداة استخبارات تنافسية موجودة |
| Market Saturation | **مطابق لـ`competition_score` الموجود فعلاً** — تسمية مختلفة لنفس الرقم |

## لماذا هذا القرار — لا رفض للرؤية، رفض للاختلاق

طلبك نفسه، قبل رسالتين، نصّ صراحةً: **"Do not fabricate data... never create fake metrics."** بناء 26 بُعداً بلا مصدر بيانات حقيقي وراءها هو اختلاق بالتعريف — بغضّ النظر عن مدى تعقيد الصيغة الرياضية التي تُغلِّفه. محرك تسجيل بـ28 حقلاً، 22 منها أرقام مُختلَقة تبدو احترافية، **أسوأ** من محرك بحقل واحد صادق — يبدو أكثر موثوقية بينما هو أقل صدقاً.

**المسار الصحيح لإغلاق أي بُعد من الـ26 مستقبلاً:** بناء مصدر بيانات حقيقي أولاً (اتصال Trends حقيقي، بيانات مبيعات فعلية، أداة استخبارات منافسين) — ثم البُعد المرتبط به يُفتَح بصدق، لا قبل ذلك.

## الأثر

- `profit_oracle.py`: استيراد `safety_filter` (مُحرَس، بلا مخاطرة دورة استيراد)، `_is_in_rejected_niches()`, `_score_risk()`, `_score_confidence()` جديدة؛ `score_opportunity()`'s مخرَج يضيف `risk`/`confidence` فقط، إضافياً بحت.
- `tests/test_opportunity_score.py`: +6 اختبارات (27 إجمالياً)، تُثبت أن `profit_score`/`verdict` لا يتغيّران أبداً بسبب هذين الحقلين.
- **لم يُستورَد `inspectors.py`** رغم احتوائه فحص تكرار حقيقي (`_is_duplicate`) — يستورد `profit_oracle` بنفسه، فاستيراده هنا كان سيُنشئ دورة استيراد مباشرة (`profit_oracle → inspectors → profit_oracle`)، بخلاف `safety_filter.py` الآمن تماماً. يمكن إضافته لاحقاً بنفس نمط `market_hunter.py`'s الاستيراد المُحرَس إن لزم، لا الآن.
