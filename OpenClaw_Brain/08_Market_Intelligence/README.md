# 08 — Market Intelligence

## Source of truth

[GOLDEN_OPPORTUNITIES.md](../../GOLDEN_OPPORTUNITIES.md) and its machine-readable twin `golden_opportunities.json` (repo root) — generated by `profit_oracle.py --run`, reading from `OPPORTUNITIES.md`. This folder does not duplicate that data; it explains how to read it and what's actually behind the numbers.

## Current real state (as of this Brain's creation)

`OPPORTUNITIES.md` has **zero real entries** — the n8n workflow node that would feed it via `POST /api/trends` has never been added (see [10_Automation](../10_Automation/)). Every score in `GOLDEN_OPPORTUNITIES.md` to date has come from manual test niches or live Scout picks logged separately in `scout_runs.log`, not from the intended automated intake pipeline.

## What "GOLDEN" actually means — read before trusting a score

`profit_score` is a blend of four signals, only some of which are real data:

| Signal | Real or estimated? |
|---|---|
| Seasonality (in-season keyword match) | **Real** — actual current date vs. a keyword calendar |
| Search volume | Estimated — word-count specificity heuristic, no live API |
| Trend momentum | **Always a neutral 50** — no Google Trends connection exists anywhere in this factory |
| Competition (if a saved `niche_reports/` file matches) | **Real** — reuses `niche_validator_v2.py`'s Amazon research |
| Competition (no saved report) | Estimated — word-count heuristic |
| Price tier / margin | Estimated — keyword-tier heuristic, now also feeds `butter_price()` |
| Execution fit | **Real** — grounded in the actual fact that only `book_engine` is active |

A GOLDEN (80+) score is a genuinely useful signal, but it is not the same claim as "Google says this is trending" — nothing in this factory has ever made that claim with real data behind it. See [19_Lessons_Learned](../19_Lessons_Learned/) for why this distinction matters (a recurring theme: never fabricate a data source that doesn't exist).

## How to regenerate this intelligence

```bash
python profit_oracle.py --run    # scores every OPPORTUNITIES.md entry, writes GOLDEN_OPPORTUNITIES.md
python profit_oracle.py          # demo mode: 3 sample niches, one of each verdict
```
