# 14 — Marketing

## Honest current state: content generation only, no distribution

OPENCLAW_OS_CONSTITUTION.md's Intelligent Marketing principle:

> The factory never waits for customers. The factory reaches customers. Generate content for: Pinterest, YouTube, Instagram, TikTok, Facebook, LinkedIn, SEO, Email, Blogs, Landing Pages, future platforms. Measure every campaign. Continuously improve conversion.

Nothing in this repository posts to any of these platforms, schedules a campaign, or measures conversion. `AGENT_PROMPTS.publisher` (see [09_Prompt_Library](../09_Prompt_Library/)) generates SEO description/keyword copy for Amazon specifically — the closest thing to marketing content generation that exists, and it's scoped to KDP listings, not the social platforms named above.

## Why this gap is expected, not a failure

Per the Golden Rule ([01_Vision](../01_Vision/)): `book_engine` hasn't proven profitable yet. Building a multi-platform marketing engine ahead of that would be exactly the kind of premature expansion the supreme law warns against. This folder is a placeholder for when that changes — the checklist above is the real spec to build against when it's time.
